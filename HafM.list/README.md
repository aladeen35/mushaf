# HafM.list — 1/2 Million Quality list

تطبيق ويب (Mobile-first) لقوائم فحص الجودة في فروع هاف مليون الـ106 — بدل تعبئة القوائم عبر واتساب أو إكسل.
ملفات ثابتة فقط (HTML / CSS / JavaScript) بلا خطوة بناء، ويعمل على GitHub Pages أو أي استضافة ثابتة، ويُثبَّت على الجوال كتطبيق (PWA).

## الصفحات

| الصفحة | الملف | المحتوى |
|---|---|---|
| الافتتاحية + الترحيب + الدخول | `index.html` | شعار متحرك ← شاشة ترحيب ← إيميل العمل ← (أول مرة: الاسم + اختيار رمز من 4 أرقام) / (زيارة لاحقة: الرمز فقط) |
| الرئيسية | `home.html` | تحية، إحصائيات الأسبوع، **بطاقة لكل قائمة** تنقلك لصفحتها، مخالفة اليوم، سؤال المراجعة، آخر إدخالاتك |

## الدخول والصلاحيات
- الدخول بـ **إيميل العمل** (`@halfm.sa` فقط — قابل للتعديل في `assets/js/config.js`).
- أول مرة: الاسم الكامل + رمز دخول من 4 أرقام (مع تأكيد). الزيارات اللاحقة: يُطلب الرمز فقط.
- الرمز لا يُحفظ نصاً، بل كبصمة SHA-256. 5 محاولات خاطئة = قفل دقيقة.
- **المشرف** (Admin): معرّف في `config.js` ببصمة إيميله (`ADMIN_EMAIL_HASHES`) — لا يُكتب الإيميل نصاً في الملف العام.
  يمنح صلاحية «محرّر قوائم» لأي إيميل، ويعيد تعيين رموز المستخدمين على الجهاز.
- **محرّر القوائم** (Editor): يضيف القوائم ويعدّلها ويؤرشفها.
- **الفاحص** (Auditor): يعبّئ الفروع ويرى التقارير فقط.
- لإضافة مشرف دائم: من «حسابي ← نسخ رمز الصلاحية» أو `printf 'hafm-admin|name@halfm.sa' | sha256sum`، ثم أضف الناتج إلى `ADMIN_EMAIL_HASHES`.

## التخزين — مهم
البيانات تُحفظ في **متصفح الجهاز** (`localStorage`، المفتاح `hafmList.v2`). لا مزامنة تلقائية بين الأجهزة.
لنقل البيانات: «حسابي ← تنزيل نسخة JSON» ثم يدمجها المشرف من «استيراد / دمج نسخة» (الأحدث يغلب لكل فرع).
بيانات النسخة الأولى (`halfMillionQualityAppV1`) تُنقل تلقائياً عند أول فتح.

## Excel
- **فحص المشروبات**: نفس قالب `Beverage_Tasting` الأصلي تماماً — ورقة `All_Branches`، A1:S117، الألوان، العمود D مخفي، القوائم المنسدلة،
  معادلات `COUNTIF`، التنسيق الشرطي (ومنه اسم الفرع بالأحمر عند وجود Not fixed)، وجدول SUMMARY BY PRODUCT. الاسم: `Beverage_Tasting_<السبت>.xlsx`.
- **أي قائمة أخرى**: نفس التصميم مع أعمدة بنود القائمة، وعمود الفاحص.
- مكتبة ExcelJS 4.4.0 تُحمَّل من CDN عند الضغط على زر التصدير فقط.
